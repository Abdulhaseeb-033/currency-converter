# Currency Converter

A responsive currency converter built with HTML, CSS, and Vanilla JavaScript. It uses the Frankfurter API to retrieve exchange-rate data and visualize historical currency movements.

## Features

- Convert between supported currencies
- Fetch the latest available reference exchange rates
- Interactive historical exchange-rate chart
- Chart filters for 7 days, 1 month, 3 months, and 1 year
- Quick Convert tool with currency swapping
- Save, select, and remove currency pairs
- Responsive layout for desktop and mobile
- Refresh rates and historical data on demand

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Frankfurter API
- Chart.js
- Lucide Icons
- Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Run `index.html` using a local development server, such as the VS Code Live Server extension.

A local server is recommended because the project uses JavaScript ES modules.

## API

Exchange-rate data is provided by the [Frankfurter API](https://www.frankfurter.app/).

The API provides reference exchange rates, which may not reflect real-time trading prices.

## Project Purpose

This project was built to practice working with APIs, asynchronous JavaScript, DOM manipulation, data visualization, local storage, and responsive UI development.
